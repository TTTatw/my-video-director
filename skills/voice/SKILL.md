# Voice — 口播/音频层

决定**这条片子的"声音"怎么组成**。区分两条轴，别混：

- **画面里的人说不说话？**
- **画外有没有人声（VO/旁白）？**

组合出来就是 routing 里的类型字典。**先选定类型，再写这一层。**

## 类型 → 各自要写什么

### 类型 A · 有声口播 (talking-head)
画面里 1 人面向镜头讲。产出：
```markdown
- 说话人：REF-0X（名字）
- 声线：____（音色/快慢/口音/紧张或松弛；用描述不用数值）
- 台词：你写的口播文案（口语、有留白、别一句到底）
- 字幕：[可选] 是否配字幕，配则用台词
```
> 台词风格：很"人话"，允许断句、语气词、自我纠正。别写成"产品说明书"。

### 类型 B · 无口播 + 字幕 (silent + subtitles)
画面里的人**不开口**，靠**镜头动作 + 字幕文案**讲。产出：
```markdown
- 画面：动作/场景叙事（见 storyboard）
- 字幕文案：每镜一句，短、有节奏、可独立成立
- 音乐/音效：情绪基底（哪一种）
- [后期] 字幕在后期加上——生成阶段不放正文
```
> 关键：**画面不能为空**，字幕只是它的"旁白"，不能反过来带节奏。

### 类型 C · 背景配音 (background VO)
画面里人**不一定说话**，**画外旁白**在讲。产出：
```markdown
- 画面：视觉在演（人物/场景/产品），不一定开口
- 背景 VO 声线：____（像 A 的声线，但常更沉稳/叙述感）
- VO 文案：旁白（能独立成故事/可搭配画面）
- 是否也要字幕：[可选]
```

### 类型 D · ASMR 静音
**没人声**，靠**音效 + 近距离声**。产出：
```markdown
- 画面：产品细节特写（拧、倒、摸、敲）
- 音效：____（对应动作的声音：盖子旋开、液体倒、织物摩擦）
- 字幕：caption-only（极少，或没有）
- 情绪：解压/沉浸/质感
```

### 类型 E · 双人对话 (dialogue)
2 人来回。产出：
```markdown
- 说话人：REF-0X(攻) / REF-0Y(守)
- 声线：各自一个
- 台词：对话（有来回、有攻守、节奏感）
- 是否需要字幕：[可选]
```

## 通用规则

0. **口播 = 人物说话 或 背景口播(BGM+画外音一直在说)，都成立；嘴型同步不是问题。** **不要默认无对白氛围片**——除非用户明确要"静音氛围"，否则优先给"有人声在讲"的口播（类型 A 人物说话 / 类型 C 背景口播）。产品带货/服装美妆通常需要人声讲解或旁白。
1. **画面中人物说不说话 ≠ 有没有人声**。类型 C 里人可以闭嘴但有人声，类型 B 里人开口了也常没字幕差异。**先确认类型，别默认"有嘴就有人声"。**
2. **屏幕上要出现的文字（字幕/贴片/标题）**：按视频生成平台的现状，**生成阶段不要写进正文**（很多模型渲染文字不可靠），统一在**后期/图片包**加。配音/字幕文案这里给清楚，标注"后期上"。
3. **一句台词一个信息**，别堆。
4. **台词和口播声线一旦定下，别逐镜换**。声线要"锁定"——同一角色用一个声线，逐字粘贴到音频字段，不换近义词。
5. **多个说话人**时，各自声线要能区分开。

## 产出说明

**口播/配音文案是这个 skill 里最"文案"的部分**，写的时候把自己当成写稿的，别当成写参数表的。
