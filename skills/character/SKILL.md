# Character — 角色系统

视频的"人"由这层定义。**判定单人 vs 多人，再逐人生卡。**

## 判定（见 `references/routing.md` 第 3 张表）

- 默认**单人**，除非明确信号。
- 多人：写**共享场景方向**，再给每人**独有动机 + objective + tactic**。
- **≤3 个可跟踪角色**，超出写成"人群/路人"。

## 角色卡模板（每角色一张）

```markdown
## ③ 角色卡 · [名字/代号 REF-01]

### 长相 (Build & Face)
- 体格/体态：____（重心高/低、站姿、肩、身材基调）
- 脸：____（眼睛、骨相、表情基准——观察可见，不写情绪）
- 年龄感：____（用描述，不用数字：一张被生活磨粗的脸 / 少年气的轮廓）
- 手/职业痕迹：____（体现身体"传记"）

### 穿搭 (Wardrobe)
- 上装 / 下装 / 鞋 / 配饰：____
- 风格关键词：____（机能 / 极简 / 元气 / 复古…）
- 与产品的关系：____（衬托产品？日常用它？）
- [可选] 场景变换时怎么保持一致：____

### 人设 (Persona)
- 身份/职业：____
- 性格：____
- 说话风格：____（如果发声）
- 与产品的关系：____（用户 / 品牌代言 / 试用者 / 旁白）

### 是否发声
- 说话人？口播还是对话？还是只出镜不发音（→ 交给 voice 层）

### 场景定位
- 在这个视频里扮演：____（主角 / 对手 / 助力 / 观察者）

## 多人时的额外一层（关键！）

`scene direction` 属于整个场景、所有人共享；`motive` 属于每个人。**别只给 objective——那是各演各的。**

```markdown
**共享场景方向 (scene direction)：** 一句话说清"这场戏所有人默契地度过的方式"。
例：一场给儿子收拾行囊送行的戏 —— "让离别没有痛感"。

**每人独有动机 (motive / fuel)：** 同一个方向，不同燃料。
- REF-01：为了让母亲好受
- REF-02：出于迷信（出发前落泪是不祥）
```

## 规则

1. **长相写"可观察"，不写情绪**。写"厚眼睑、慢眨眼"，不写"看起来很累"。情绪是 acting 层的事。
2. **穿搭独立成卡**，别混进 acting。它必须能扛住换场景。
3. **年龄用描述**：'生活的磨砺写在脸上'、'旧拳手的气场'——不写"25 岁""少女"。
4. **每个角色有"存在感"**，不是背景板。即使只出镜不说话，也要有该做的任务（决定他/她的眼神和反应）。
5. **发声角色**才定说话风格；不发声的只写出镜人设 → 交给 voice 层处理字幕/VO。

## 产出说明

单人就一张卡；多人就 N 张卡 + 共享方向块。**角色卡是分镜和 acting 的"引用源"**，后面用 `REF-0X` 指代即可，避免每处重写。
