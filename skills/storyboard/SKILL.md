# Storyboard — 分镜

把"要拍什么"落成**逐镜头规格**。这一层是"镜头语言"，不是剧情。

> 镜头语言规则来自电影实拍工艺（采编自 storyboard-director 参考）。核心排序：**物理可行性 > 叙事情绪 > 多样性**。一个用错时机的环绕镜头，比不用更糟；一个越轴的固定镜头，比不放更出戏。**绝不允许"默认平视+固定"的偷懒拍法，也不允许"为凑炫技硬塞不合理镜头"。**

## 每一镜的规格（镜头描述在前，人物/动作在后）

每个镜头严格按下面字段顺序写。`画面内容` 在前、`人物在做什么` 在后，正好是你说的"先镜头、后角色"。

```markdown
### 镜头 XX
- **景别**：大远景/远景/全景/中全景/中景/近景/特写/大特写
- **焦段**：焦段 + 用途（例：中长焦 85mm · 人像黄金段，肤质细腻、背景压缩）
- **机位角度**：平视/仰视/俯视/鸟瞰/荷兰角/过肩/POV + 高度 + 情绪目的
- **景深**：浅/深/焦点转换 + 焦点落在哪
- **运镜**：固定/推/拉/横移/竖移/跟拍/摇/俯仰/环绕/滑动变焦/手持 + 情绪匹配
- **纵深机制**：光/曝光分离 或 大气透视 或 遮挡/尺度递退（**只选一种，不堆叠**）
- **光源动机**：光线类型 + 来源锚点 + 方向/衰减（室内必须绑定锚点）
- **构图**：三分法/居中对称/引导线/框架/负空间
- **画面内容(状态)**：写下屏幕能看到的（人物位置姿态绑定锚点；写"正在发生的瞬间"不是摆拍清单）
- **人物在做什么**：本镜在场角色的具体动作
- **转场**：硬切/叠化/慢放/音桥视桥/动作匹配
```

> **低预算/短视频也不省这些字段**——它们是让镜头有质感的最小集。

## 镜头语言分寸表

### 景别 ↔ 情绪
| 情绪 | 景别 |
|---|---|
| 情绪越强 | 越紧（特写/大特写） |
| 动作越大 | 越松（全景/远景） |
| 定场/环境 | 中景/全景 |

**反规则（重锤情绪反着用更有力）**：悲伤/绝望爆发 → 反而**拉远**；震惊/认知崩塌 → 反而**固定大特写**；暴力瞬间 → 反而**切空镜/拉远**；孤独/被弃 → 反而**大景别人物居中**。每场至少识别 1 个反规则机会点。
**对话开场**：第一镜必须是**中景/全景**交代空间关系，禁止一上来就特写。

### 焦段 ↔ 叙事
| 焦段 | 用途 |
|---|---|
| 超广角 14–24mm | 史诗/建立镜头/宏大环境 |
| 广角 24–35mm | 环境交代/室内全景/群体 |
| 标准 35–50mm | 日常叙事/中景对话/客观记录 |
| 中长焦 85mm | 人物特写/肖像/情绪逼近/背景压缩 |
| 长焦 135–200mm | 远距观察/偷窥/孤立感/体育 |
| 微距 1:1 | 物件细节/泪滴/纹理/关键道具 |

人物特写优先 **85mm**（禁广角拍近景，除非刻意丑化）；大景别优先 **广角/超广角**（禁标准焦段拍大远景——平淡无空间感）。

### 机位角度 ↔ 情绪
| 角度 | 情绪 |
|---|---|
| 仰视 | 力量/威严/英雄/压迫 |
| 俯视 | 弱小/孤独/无助 |
| 鸟瞰 | 全知/宿命/地理 |
| 荷兰角 | 失衡/疯狂/悬疑 |
| 过肩 | 对话空间关系 |
| POV | 沉浸代入 |

**权力不对等用角度**：强者仰拍、弱者俯拍。**反规则**：阴险反派用平视/微仰（大仰拍反而"崇高"化）；失败者尊严用平视；受害者恐惧用仰拍施暴者。全片至少 1 次仰拍 + 1 次俯拍，连续 3 镜不得全平视。

### 运镜 ↔ 情绪强度
| 情绪强度 | 运镜 |
|---|---|
| 平静 | 慢/静止 |
| 紧张上升 | 中速/微晃 |
| 爆发/混乱 | 快/突变/手持 |
| 震撼/凝固 | 固定大特写/滑动变焦/环绕 |
| 留白/平复 | 静止/极慢拉镜 |

**运镜速度 = 情绪强度**；固定镜头占比 ≤30%（禁连续 3 个固定）。重技法（滑动变焦/环绕/鱼眼/荷兰角/升降/POV）是稀缺资源，**只在"重锤瞬间"用**，且有频率上限（滑动变焦全片≤1、环绕全片≤3、鱼眼≤2、荷兰角≤4、升降≤2）。没有重锤瞬间的戏，就不要用重技法。

## 三条纵深主层机制（只选一种，不堆叠）

1. **光/曝光分离**——主体靠有来源的轮廓光/明暗与背景分离。
2. **随距离衰减的大气透视**——远景随距离降对比、轻微去饱和并偏冷，**结构与边缘仍清晰**（不是结构分辨率下降）。
3. **遮挡/尺度递退**——场景已有重复建筑/地形/人群，写重叠与尺度递减。

**禁止**用 fog/haze/blur 当万能纵深捷径。场景没有雾/烟/尘/蒸汽/海雾/风雪等可见介质时，**禁止写体积雾或可见光束**。

## 光源动机铁律

**画面每一处亮度都必须有明确来源、方向与真实衰减。**
- 室内光源**必须绑定锚点**（窗户/灯具/火源/屏幕/霓虹），禁"无来源侧光"。
- 室外光源写明类型：太阳（黄金时刻/正午/阴天）/ 月光 / 街灯（钠灯/汞灯）/ 霓虹招牌 / 车灯 / 火光。禁"侧光""环境光"。
- 光的衰减要真实（近亮远暗、有落点、有明暗交界）；禁"全局均匀补光"。
- **物理雾双检**：只有同时满足 ①场景有可见介质 ②有具名光源带方向衰减，才写体积光；任一条不满足就省略。真空太空永不加大气雾。
- **黄金时刻优先**：默认自然光、优先黄金时刻（低角度、5000–5500K、长阴影、逆光镶边）；只有场景有尘/雾/喷雾时才写可见光束。

## 景深策略

| 景深 | 适用 |
|---|---|
| 浅景深 | 人物特写/肖像/情绪聚焦/孤立主体 |
| 深景深 | 大景别/环境/多人关系/全景 |
| 焦点转换 | 视线引导/关系转换/揭示 |

## 构图法

| 构图 | 用途 |
|---|---|
| 三分法 | 日常叙事默认 |
| 居中对称 | 仪式感/压迫感/宿命感 |
| 引导线 | 道路/走廊/光影引视线 |
| 框架构图 | 门窗/拱门/前景框住主体（窥视/隔离） |
| 负空间 | 主体偏侧留大量空（孤独/渺小） |

## 场景空间类型物理上限（先匹配空间，再谈情绪）

一个镜头先过"物理可行"这一关。精简版关键红线：
- **室内小/中空间（S1/S2）**：最大景别=**全景**；禁大远景/远景、禁鸟瞰、禁升降/摇臂、禁长焦>135mm、超广角<24mm 拍人物近景。
- **室外开阔（O1）**：大远景/鸟瞰/升降的主场。
- **特殊封闭（X，车内/电梯/楼梯间）**：最大景别不超中全景；禁横移/拉镜/轨道/环绕/过肩。
- **过肩**要机位能退到人物身后 1.5–2m；**拉镜/横移/环绕**要机位背后有退让空间。画面里若人物背后是墙，拉镜会撞墙。
> 优先级铁律：**物理可行 > 叙事情绪 > 多样性**。

## 非人物镜头（产品片的"呼吸"）

拍人脸会"人脸接力"变疲劳；**在人物镜头之间穿插非人物镜头**（手部特写、物件特写、环境空镜、光影变化、局部肢体），让观众"看见"而非"看完"。对产品片尤其有用：
- **手部/局部**：展示产品质感、使用动作（端杯、拂裙摆、拧盖）——比整张脸更能承载细节与情绪。
- **物件特写**：产品本体的质感、结构、纹理。
- **环境空镜**：氛围、地点、时间。
- **光影变化**：时间流逝/情绪转折。
> 这些是非人物镜头，画面描述标"无人物/局部不露脸"，台词/旁白在画外延续。**穿插比例参考 30–50%，且每个非人物镜头要有情绪/信息理由（不是凑数空镜）。**

## 连续性衔接（多镜/对话/有转场时）

- **30° 规则**：同一主体相邻两镜，机位角度差 ≥30°，或用焦段差异弥补，否则跳切。
- **景别跳跃 ≤3 级**：全景→大特写（5 级）= 断裂，要加过渡或中间景别。
- **视线匹配**：上一镜像某处，下一镜切到落点。
- **运镜节奏衔接**：上一镜固定 → 下一镜不能突然快运（要过渡）；运动→固定是合法"句号"。
- **180° 轴线**：对话/对峙场景机位在两人连线同一侧，禁越轴（对话才需要）。

## 铁则（保留）

- **状态，不是过程**："手臂前伸、已扔出"，不写"伸手抓住、再扔"。
- **≤3 个可跟踪角色**；多出的写"人群/路人"。
- 每镜用 `REF-0X` 引用角色卡，别重写长相。
- 一镜一个信息，别在 3 秒塞三件事。

## 产出说明

- **镜头规格在前、人物/动作在后**（如你所说）。
- 分镜表是 `acting` 的底板——每镜有哪几个 `REF-0X` 在画面，acting 就为谁写；也是 `final-prompt` 的输入，`画面内容/光源/纵深/构图` 会汇入最终的视觉描述。
