# Templates — 10 种 UGC 模板（快路径）

给"就要一条"的用户。**选模板 → 选概念种子 → 填脚本**即可。仍可升级到导演路径。

## 使用方式
1. 按产品/目标选一个模板。
2. 从该模板的"概念种子"里挑一个有新意的。
3. **配齐短视频工艺**（必须，不是可选项）——从 `references/short-video-craft.md` 取：
   - **3 秒钩子**：选一个钩子原型 + 一句具体开头（配 3–5 字屏幕字 + 开场快动作）。
   - **留人结构**：钩子 → 价值 → CTA；长视频每 5–7s 补一个"再钩"；可选结尾 loop。
   - **心理杠杆**：按产品挑 1–2 个主打（服装/美妆尤其用"自我镜像/变身/不费力/值得"）。
   - **反转**：能加就套一个，**必须落回产品**。
   - **口播**：人物说话 或 背景口播都行——**不要默认无对白**；只有用户明确要"静音氛围"才走无缝/ASMR。
4. 按模板时间轴 + 工艺填出脚本（角色卡 + 分镜 + 口播类型）。

## 01 · 口播测评
- **类型**：A · 单人 · 15–25s
- **时间轴**：钩子(3s 一句话/一动作) → 卖点(12s 手持+讲) → CTA(5s 去装/去试)
- **概念种子**：盲测给分 / "先说缺点再说优点" / "我一周真实使用报告" / "和普通款对比" / 值不值这个钱
- **角色**：一个真实感强的讲述者

## 02 · 开箱揭秘
- **类型**：A · 单人 · 20–30s
- **时间轴**：悬念(快递盒/拆封) → 揭晓(产品出屏) → 细节特写+口播 → CTA
- **概念种子**：三重开箱(盒中盒) / 手忙脚乱差点掉 / 赠品意外 / "就这包装也值了"
- **角色**：一个情绪放大的开箱者
- **特别**：揭晓时刻是记忆点，别平铺。

## 03 · 好物清单
- **类型**：A · 单人 · 25–40s
- **时间轴**：开场"我最近回购的X样" → 逐样展示(每样 3–5s) → 重点推一个 → CTA
- **概念种子**：办公室/通勤/宿舍场景限定 / 用过就回不去的 / 平价替代 / 送人清单
- **角色**：一个日常感的分享者

## 04 · ASMR 质感
- **类型**：D · 无/手 · 15–25s
- **时间轴**：静态特写 → 一个动作(拧/倒/摸) → 另一个动作 → 画面定格收尾
- **概念种子**：开盖一滴落 / 台灯下质感 / 拉近到表面 / 缓慢转场
- **角色**：无，只有手/产品
- **特别**：靠**音效 + 特写**撑，字幕极少。

## 05 · 前后对比/改造
- **类型**：B · 单人/无 · 20–30s
- **时间轴**：before(素/乱) → 使用/改造动作 → after(明显变化) → 字幕总结
- **概念种子**：一镜对比 / 左右分屏 / 还原一整天 / 素脸 vs 上妆
- **角色**：一个"被改变"的主人公
- **特别**：before/after 落差是记忆点。

## 06 · 痛点-解决方案
- **类型**：A 或 E · 1~2 · 20–30s
- **时间轴**：展示痛点场景 → 引入产品 → 解决过程 → 结果 + 一句总结
- **概念种子**：日常崩溃瞬间 / 两个朋友吐槽 / "我本来不信" / 多场景演示
- **角色**：可单人口播，或一人提问一人解决（更戏剧）。

## 07 · 生活场景代入
- **类型**：B 或 C · 单人 · 20–35s
- **时间轴**：清晨/通勤/夜晚等场景 → 产品自然出现 → 情绪落点 → 字幕/VO
- **概念种子**：赶地铁的咖啡 / 深夜加班台灯 / 周末独处 / 下雨天的伞
- **角色**：一个"这个场景里的你们"
- **特别**：靠**氛围**和**代入感**，不靠讲卖点。

## 08 · 挑战/悬念
- **类型**：A · 单人 · 15–25s
- **时间轴**：立挑战/悬念 → 尝试 → 结果(反转/成功) → 反应 + CTA
- **概念种子**："能不能X秒内完成" / "$100试试值不值" / 出乎意料的结果 / 朋友赌我做不到
- **角色**：一个带点玩心的主角
- **特别**：反转/意外是记忆点。

## 09 · 街访/路人反应
- **类型**：A 或 E · 2~多人 · 20–30s
- **时间轴**：抛出问题/给产品 → 路人真实反应 → 采访/对话 → 总结
- **概念种子**：路人盲测打分 / "猜猜多少钱" / 给陌生人试吃 / 街边随机
- **角色**：主持人(可单人) + 路人
- **特别**：真实感强、高信任度；**路人按"人群"处理，不做单卡**。

## 10 · 安静治愈
- **类型**：B 或 D · 单人/无 · 20–30s
- **时间轴**：慢镜头场景 → 产品静置/使用 → 平静收尾 + 少量字幕
- **概念种子**：黄昏窗台 / 一壶茶的独处 / 香薰灯下 / 雨夜读书
- **角色**：一个安静的享受者 / 或无人物只有产品
- **特别**：关键在于节奏慢、留白多、不吵。

## 快路径产出

选好模板 + 种子后，按 root SKILL.md 的六段格式产出一份**简版拍摄案**（角色卡简版 + 分镜(用模板时间轴) + 口播类型）。用户想要更深，一句话切到导演路径即可。
