# Treatment — 创意层

从"这个产品是什么"升级到"这个视频**要让人记住什么**"。这是整套 skill 里最像人类编导的一步，也是模板给不了的一步。

## 流程

```
产品画像
  ↓ ① 找洞察 (insight)：产品解决的那个"真实瞬间"
  ↓ ② 提炼 Big Idea：一句让人记住的主张
  ↓ ③ 出 2~3 个创意方向，每个落到 video 类型 + 节奏 + 记忆点
  ↓ ④ 给出默认推荐的 1 个(听话且有新意)
```

## ① 找洞察 Insight

别从"我的产品很好"出发，从**用户的真实处境**出发。问三句：
- 用户在什么**尴尬/麻烦/渴望**的瞬间想到这个产品？
- 这个产品给了用户什么**变化**（不仅是功能，是感受）？
- 有什么**反直觉**的角度大众还没被戳中？

> 好的洞察 = 用户自己没说出、但一听就"对"的那句话。

## ② Big Idea

**一句话**，是这整个视频要建立的**单一主张**，让人看完记得住。
- 不是一个梗、不是一句文案，是"这个片子在说什么"。
- 好标准：**一句话说清 + 有记忆点 + 能撑起整条片子**。

例：便携咖啡杯 → 不是"好喝"，而是"**在赶路的人，也值得一杯像样的咖啡**"。

## ③ 创意方向 Concept

每个方向 = 一个**可执行的角度**（不是空泛 slogan）。每个给 4 项：
- **一句话 concept**（画面里会发生什么）
- **视频类型**（对应 routing 的第 2 张表：A 口播 / B 字幕 / C 背景配音 / D ASMR / E 对话）
- **节奏**（快切/中速/慢放、紧张/松弛、密度）
- **记忆点**（镜头/音效/一句台词/一个动作，让这条区别于别人）

## ④ 推荐

从 2~3 个里**明确推荐 1 个**，并一句话说明为什么（最贴合人群/最有记忆点/性价比）。用户可一句"换成 2"即切换。

## 规则

- **方向之间要有差异**，别是同一个点换皮。
- 一个方向只立一个记忆点，别贪多。
- 视频类型选择是终点（决定了 character/storyboard/voice 怎么走），所以**每个方向都要落到具体类型**。

## 产出

```markdown
## ② Big Idea
"____"

## ③ 创意方向
- 方向1 · concept / 类型 / 节奏 / 记忆点
- 方向2 · …
- 方向3 · …

## ④ 推荐
✅ 方向1 —— 因为…
```
