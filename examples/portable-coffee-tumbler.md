# 示例 · 便携咖啡杯 → 完整拍摄案

> 演示 `my-video-director` 一次完整调用（导演路径）的输出形态。输入：一张便携保温咖啡杯的产品图 + 需求"做成一条 20s 口播 UGC，单人，带字幕"。

---

## ① 产品画像

- 品类：便携保温咖啡杯 / 随行咖啡杯
- 核心卖点：保温保冷（图片上能读出的保温杯造型）；轻量、可挎；随手可带
- 目标人群：通勤路上要喝咖啡的人；赶时间但不想喝速溶的人（用描述：被早高峰逼着走的人）
- 调性/色板：哑光、莫兰迪色 / 机能简约感 —— 适合"不将就"的日常感
- 人群痛点：咖啡凉了；外带杯不环保；咖啡店排队久
- 使用场景：地铁、通勤路、办公室、周末出行
- 语言风格：口语、真实、有点自我调侃；不端着

---

## ② Big Idea

**"赶路的人，也值得一杯像样的咖啡。"**

- **方向1 · 通勤救赎** — type A 口播
  - concept：早高峰地铁里，他从包里掏出自己的咖啡，不用排队、温度刚好
  - 节奏：中快切，前紧后松
  - 记忆点：在拥挤车厢里"给自己留一杯"的反差
- **方向2 · 降温神器** — type B 无口播+字幕
  - concept：一镜跟拍他在烈日/寒冬里，杯子始终是合适温度
  - 节奏：慢，叠化，质感
  - 记忆点：温度反差（冬天不凉 / 夏天不热）
- **方向3 · 打工人自嘲** — type A 口播（对话感自白）
  - concept：他对着镜头吐槽"以前咖啡店排队，现在我自带一台'移动吧台'"
  - 节奏：轻快、有梗
  - 记忆点：一句自嘲台词

## ✅ 推荐 方向1 —— 最贴人群、最有记忆点、克制不浮夸。

---

## ③ 角色卡（单人）

### REF-01 · 通勤者
- **长相**：一张没睡够但硬撑着的脸；眼周略薄，单眼皮偏清秀；身材中等、微微驼背；走路带点赶劲。年纪感：三十上下的职场人，写在眉眼的不耐烦里。
- **穿搭**：深色圆领毛衣 + 通勤外套 + 帆布包；莫兰迪/黑灰系，和杯子调性一致；
- **人设**：都市上班族；嘴硬心软，爱自嘲；说话节奏快、带点不耐烦但也有温度。
- **是否发声**：是，口播。
- **场景定位**：主角。

## ⑤ 表演层 · REF-01

**镜头 01**
- Objective：让看的人觉得"我也常这样"。
- Obstacle：镜头是假的，他得自己先信。
- Beats：起(吐槽) → 顿(掏包) → 快(接话)。
- Subtext：嘴上说"忙"，眼神是想被理解。
- Business：一手扶着耳机线，一手要掏包。
- Eye-life：扫一眼车厢再落回镜头；比开口早半秒。
- Status：不卑不亢，普通人的从容。

**镜头 03**
- Objective：证明"自带真的省事"。
- Tactics：用"事实"压（没排队、温度刚好），不是用"口号"。
- Beats：报时间 → 拿杯示意 → 停顿让他自己品。
- Subtext："我比你们聪明"其实是想被认同。
- Business：手机在另一只手，随时看时间。

**镜头 05**
- Objective：让"赶紧去弄一杯"的念头留下。
- Beats：喝一口(享受) → 微微眯眼 → 抛给观众。
- Subtext：一句"你也该对自己好点"，但不说出口。
- Business：喝完轻轻晃杯。
- Eye-life：喝完那下眼皮放软，是最真的瞬间。

## ⑥ 口播类型 · A 有声口播

- **说话人**：REF-01
- **声线**：三十上下，普通话带点北方口音，语速偏快但喘得均匀，带点懒散的不耐烦。语气不端着，像跟朋友吐槽。
- **台词**（口语化）："以前吧，我每天得排队买咖啡，还凉得快。现在？包里一掏，温度刚好。你说这是省事？这是给自己留口'日子'。不管多赶，这一口，是我的。"
- **字幕**：[后期上] 用台词精简成 2~3 行短句，不要全文。
