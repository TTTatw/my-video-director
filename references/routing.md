# Routing — 路径判定 + 视频类型字典 + 角色数判定

根路由器的决策依据。三张表：**路径判定**、**视频类型字典**、**角色数判定**。

---

## 1. 路径判定：快路径 vs 导演路径

先判用户意图，再决定走哪条。**宁可降级也别让想创意的人拿到套模板。**

| 用户意图信号（听到这类话） | 判定 | 走哪条 |
|---|---|---|
| "就要一条 UGC 视频 / 别多想，直接给 / 套个模板就行" | 快路径 | template |
| "给我做一条开箱 / 测评 / 好物分享" | 快路径 | template（但可提示升级到导演） |
| "要有剧情 / 要有创意 / 像编导做 / 分镜 / 角色刻画" | 导演路径 | creative |
| "要根据我产品想个有意思的点子" | 导演路径 | creative |
| 只给了图片 + 一句话需求，没说要模板 | **默认走导演路径** | creative |
| 没有需求，只给了图片 | 先问一句"走模板还是走创意"，别默认 | 视回答 |

**降级原则：** 导演路径实际能力包含快路径。用户说"先来条快的"，走 template；用完想升级，补一句"再给我个有剧情版本"即可切到 creative。

---

## 2. 视频类型字典（决定 voice / 字幕 / audio 分支）

这是本 skill 的核心归纳——开源里是散的，这里统一成 5 类。**先选定类型，后面 voice/storyboard 都按它走。**

| # | 类型 | 说话人 | 字幕 | 声音/配乐 | 适用 | 结构特点 |
|---|---|---|---|---|---|---|
| A | **有声口播 (talking-head)** | 1 人面向镜头讲 | 可无/可加 | 人声为主 | UGC 测评、产品推荐、开箱 | 口播为主，产品手持出镜 |
| B | **无口播 + 字幕 (silent + subtitles)** | 无说话 | 有字幕 | 音乐/音效为主 | 场景化、情绪化、产品展示 | 动作+字幕文案，节奏靠镜头 |
| C | **背景配音 (background VO)** | 画面里人不说话，画外有 VO | 可无/可有 | 画外旁白 | 广告片、故事化、品牌片 | 视觉演 + 画外解说 |
| D | **ASMR 静音** | 无说话 | caption-only | 音效/近距离声 | 产品细节、质感、解压 | 特写+声音，字幕极简 |
| E | **双人对话 (dialogue)** | 2 人对话 | 可无/可加 | 人声 | 剧情化、有冲突 | 一攻一守，节奏靠来回 |

**选择建议（按产品/目标）：**
- 电商基础款、跑量 → **A 口播**（最快、最多人用）
- 有质感/轻奢 → **B 无口播+字幕** 或 **D ASMR**
- 想讲故事/品牌 → **C 背景配音**
- 想戏剧性 → **E 双人对话**

## 3. 角色数判定：单人 vs 多人

**判定依据：** 视频类型 + 用户需求 + 产品演示是否需要第二人。

| 信号 | 判定 |
|---|---|
| 类型 A/D，用户没说多人 | 单人 |
| 类型 B，纯产品出镜 | 单人（甚至"无角色"，只有手/产品） |
| 类型 C 背景配音 | 1~2 人（画面人物 + 画外 VO） |
| 类型 E 对话 | 必须 2 人 |
| 用户提到"他/她和我""两个朋友""家人" | 多人 |
| 产品需要"试用者 + 介绍者"两角色 | 多人 |

**判定规则：**
- 默认 **单人**，除非有明确信号。别默认堆多人（多人更难保持一致性）。
- **≤3 个可跟踪角色**——超过 3 个的角色在成片里基本保不住一致性（模型引擎上限），超出部分写为"人群/路人"，不做单独角色卡。
- **多人时**：写一个**共享的场景方向 (scene direction)**，然后每个角色再给**自己的动机 (motive / 燃料) + objective + tactic**。这才是"一个场景里的几个好表演"，不是各演各的。

---

## 4. 判定后的产出骨架

**两条路径都产出完整 ①~⑦，⑦ 都是最终 Seedance 2.5 提示词。** 差别只在"创意从哪来"：

- **模板路径 (template)** → 选模板 + 概念种子作为②(创意)的输入，然后仍走全流程 ①~⑦。
- **导演路径 (creative)** → 洞察 + Big Idea 作为②，然后走全流程 ①~⑦。

**没有"精简/广告版"这一档**——⑦永远按 Seedance 2.5 规范，表演层永远做满。**先定类型（第 2 张表）再往下写**——它决定后面所有内容。
