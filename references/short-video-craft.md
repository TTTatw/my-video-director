# Short-Video Craft — 短视频工艺层（钩子 / 留人 / 心理拿捏 / 反转 / 美妆时尚心理）

给 `templates` 用的工艺库。**模板只给"格式"，这层给"手艺"**——让"3 秒钩子、留人、心理拿捏、反转"不再靠碰运气。

> 核心前提（纠正旧观念）：**口播 ≠ 只能人物说话。** 可以是①画面里人物对着镜头说话，或②人物不开口、**背景音/画外音一直在说**，或③有 BGM + 一句画外音；**嘴型同步不是问题**，背景口播完全成立。视频类型 A（有声口播）和 C（背景配音）都是"有人声在讲"，只是**说话的人是否在画面里**的区别。

---

## 一、3 秒钩子（开头 1–3s + 第一行屏幕字）—— 抖音/TikTok 尤其重

FYP 滑得快、种子队列小，**前 3 秒的留存是最干净的信号**。钩子挂了，后面什么都白搭。

### TikTok 特异性
- **默认开声音**：视觉和听觉两轨都要成立（静音时视觉扛、有音时台词扛）。
- **零跑道**：观众刚从上一个视频滑过来，第一帧就要能跟上一个视频抢。
- **格式会被当信号**：片头 logo / "欢迎回来" 这种频道式开头会被降权。**先上内容，别上品牌。**

### 钩子原型（每套生成 6–10 条、不同原型混用，别一条改 6 遍）
| 原型 | 一句话 | 为什么留住人 |
|---|---|---|
| **动作中间切入 (Middle of action)** | 镜头已经在倒、在涂、在拎、在跟人说话、在走出门 | 观众"中途进场"，得留下来搞清楚发生了什么 |
| **反常规断言 / 打破预期 (Pattern interrupt)** | "贵咖啡机就是你咖啡难喝的原因。" | 制造一个必须被闭合的好奇缺口；**结论要在结尾兑现，否则口碑崩** |
| **自白 / 内幕 (Confession)** | "我在咖啡行业。我不该喜欢这个。我天天用。" | 自白=主播冒了社交风险，观众潜意识读成"真诚" |
| **藏着不说 / 产品 tease (Withhold)** | "品牌我不说，但这是我的皮肤，4 周。" | 留到结尾才揭晓，评论区会问"是什么"→ 喂对话信号。**不要藏太久显钓鱼** |
| **视觉 + 台词复合 (Visual + verbal)** | 慢倒、冰裂 + 字幕"那个 $39 的东西悄悄替我换了一整柜。" | 同时拦住"静音党"和"开声党"，对 demo/开箱尤其强 |
| **感官锚 (Sensory anchor)** | 拆封的封膜声、满足的纹理、不寻常的特写 | 新奇信号是**前认知**处理，观众还没决定就停住了 |
| **结果先给 (In media res)** | 分屏"before"已在右边 + 字幕"这个 $12 的东西怎么救了我的头发。" | 回报立即可见，好奇心变成"这怎么发生的" |

### 炸掉 3 秒悬崖的反模式
- 第 1 帧 logo / 开场动画（烧 1–2 秒 + 频道信号）。
- "嘿，欢迎回来"（只把观众圈成老粉）。
- 先说"今天聊聊为什么 X 很重要"（输给真正的那句）。
- 品牌先行："看看我们的新品"（先给观众最不关心的）。
- 空洞好处："提升你的日常"（没有名词/数字/筹码）。
- 需要解释的机灵（观众要解码的梗，输给一句秒懂的白话）。

### 生成钩子组的规则
- **6–10 条，跨原型，别一条换皮。**
- **每条标原型**，让用户学会模式。
- **先给回报或筹码**，绝不给开场白、绝不给品牌。
- **第一行要具体**：一个数字、一个具名事物、一个带筹码的词。
- **读出来**：超过 ~2 秒说不完就砍。
- **配屏幕字**：3–5 字加粗 + 开场快动作。

## 二、钩子之后的脚本结构（留人 + 转粉）

- **钩子(0–3s) → 主体价值/证明 → CTA。** 长视频**每隔 ~5–7s 补一个"再钩"**（小反转/下一个悬念/新信息），防止中段流失。
- **开场钩**兜住前 3 秒；**中段钩**扛住 5–10 秒；**结尾**要么闭环（CTA），要么**循环**（结尾接回开头，诱导循环播放，算法加分）。
- **"wait for it"（等它出现）** 是极强的中段钩：先承诺"结尾你会看到的"，把观众钉到结尾。
- **结尾 CTA**：具体、一次性、低压力（"评论区扣个'要'" / "链接在橱窗"）。

## 三、心理杠杆（拿捏人性）

| 杠杆 | 怎么用 | 例子（服装/美妆） |
|---|---|---|
| **好奇缺口** | 先说结果/把关键藏到结尾 | "结尾再看它上身是什么样。" |
| **损失厌恶** | 强调不做的代价 | "再不买，这件就没了。" / "错过这趟，又要等补货。" |
| **社会证明** | 数字、评论区、别人都在用 | "评论区都在问这件……" / "爆了，补了三次货。" |
| **FOMO / 稀缺** | 限时/限量/倒计时 | "就这周。" / "只剩 30 件。" |
| **确认偏差 / "这就是你"** | 让观众在主角身上看到自己 | "是不是你，明明衣柜满了还觉得没衣服穿。" |
| **身份 / 自我代入** | 把产品=观众想成为的样子 | "穿上，你就是那个不用解释的人。" |
| **"你值得" / 自我奖励** | 把购买=对自己好，不是虚荣 | "给自己一件，不该有负罪感。" |
| **不费力 / 低门槛** | 消除"我撑不住"的恐惧 | "不用会搭配，套上就对。" |
| **痛点放大** | 先放大尴尬/麻烦，再给解法 | "一到约会就不知道穿什么？" |
| **锚定** | 先给高价/高价值，再给价格 | "专柜 699，这里 129。" |

## 四、反转结构（有剧情、有反转）

一个可复用的反转框架：**误导铺垫 → 升级 → 单拍落回产品。**

**经典反转模板（带货向）：**
1. **"你以为约会，其实在卖货。"** —— 男生搭讪/暧昧抬到高点，她缓缓转手机：她在直播，"链接 129，给你留一条？"（产品即商品）
2. **"你以为拒绝，其实是认可。"** —— 她冷淡/被误解，结尾才揭晓她是认可/在等它。
3. **"你以为是别人，其实是她自己。"** —— 一个"被夸"的误会，结尾落回"她/这条裙"。
4. **"你以为翻车，其实是反转爆单。"** —— 前面看似失败/尴尬，结尾一转成了卖爆。
5. **"价格赌注"** —— 猜价格/盲测，结尾揭晓（低/值），落在产品价值。

> 反转必须**落回产品**（才是带货），且**铺垫要"误"得够真**（观众真的信了），反转才爽。

## 五、美妆 / 服装 / 穿搭心理（拿捏女性对美的追求）

**核心：让观众在主角身上看到"理想中的自己"，而不是看模特。**

| 心理 | 用法 |
|---|---|
| **"这就是我" / 自我镜像** | 用真实身材/素人感/真实动作，别用完美模特；"这就是你穿上的样子。" |
| **变身 / "wait for it"** | before→after / 素 vs 妆 / 随手一套→整体升华；"看到最后。" |
| **被注意 / 被认可** | "走进去，周围会看你一眼。" / "被夸的那一下。" |
| **身份 / 状态野心** | 产品=想成为的样子："不用解释的那件""不费力就很体面"。 |
| **不费力 / 低门槛** | "不用想怎么搭""套上就对" —— 消除"我不会搭/我撑不住"的恐惧。 |
| **自我奖励 / 值得** | 购买=对自己好："给自己买件好看的，不需要理由。" |
| **社会证明 / 趋势** | "这件最近大家都在问""评论区刷屏""补货三次"。 |
| **场合-身份** | 直接点出她的场合："约会""通勤""周末""有重要的人要见"。 |
| **版型 / 遮与露** | 点出版型承诺："遮想遮的，显想显的"（显腰/遮手臂/显腿长）。 |
| **好奇产品本身** | "猜价格""等它转起来""上身那下"。 |
| **稀缺 / FOMO** | "就剩几件""就这几天"。 |

## 六、怎么用（给 templates / final-prompt 的调用方式）

选好模板后，**从这个库里给它配齐**：
1. **钩子**：从「一」选一个原型 + 一句具体开头（配 3–5 字屏幕字 + 开场快动作）。
2. **心理抓手**：从「三/五」按产品（尤其服装美妆）挑 **1–2 个**主打。
3. **结构**：钩子 → 价值 → CTA，长视频每 5–7s 补一个"再钩"，结尾 loop 或闭环。
4. **要不要反转**：能加就按「四」套一个，落回产品。
5. **口播**：人物说话 OR 背景口播都行；**别再默认无对白氛围片**。
